6) One-time Pad Tampering

"So, the One Time Pad is proven to be secure... but only in the Confidential sense! It actually does not guarantee anything about Integrity. This challenge asks you: what if you could tamper with the message in transit? Think about how XOR works, and see if you can get the flag!"

This is the challenge code:

#!/usr/bin/exec-suid -- /usr/bin/python3 -I

from Crypto.Util.strxor import strxor

import time
import sys

key = open("/challenge/.key", "rb").read()

while line := sys.stdin.readline():
    if not line.startswith("TASK: "):
        continue
    data = bytes.fromhex(line.split()[1])
    cipher_len = min(len(data), len(key))
    plaintext = strxor(data[:cipher_len], key[:cipher_len])

    print(f"Hex of plaintext: {plaintext.hex()}")
    print(f"Received command: {plaintext}")
    if plaintext == b"sleep":
        print("Sleeping!")
        time.sleep(1)
    elif plaintext == b"flag!":
        print("Victory! Your flag:")
        print(open("/flag").read())
    else:
        print("Unknown command!")

The way I solved it is that I sent an input like "aaaaaaaaaa", it turned it into \aa\aa\aa\aa\aa, XOR'ed it with the key and gave us the result. We can XOR our input and what it gives us to get the key, then we xor b"flag!" with our key and send the result to the program.

from pwn import *

p = process('/challenge/run')
context.log_level = 'info'
known_flag = b""

TOTAL_BLOCK = 128

for i in range(1,65):
    codebook = {}
    padding_len = TOTAL_BLOCK - len(known_flag) - 1
    padding = b"A" * padding_len

    for j in range(32, 127):
        guess_byte = bytes([j])
        payload = padding + known_flag + guess_byte
        p.sendlineafter(b"Choice? ", b"1")
        p.sendlineafter(b"Data? ", payload.decode('latin-1'))
        p.recvuntil(b"Result: ")
        ct_hex = p.recvline().strip()
        ct_bytes = unhex(ct_hex)
        target = ct_bytes[112:128]
        codebook[target] = guess_byte

    p.sendlineafter(b"Choice? ", b"2")
    p.sendlineafter(b"Data? ", padding.decode('latin-1'))

    p.recvuntil(b"Result: ")
    ct_hex = p.recvline().strip()
    ct_bytes = unhex(ct_hex)

    real_target = ct_bytes[112:128]

    if real_target in codebook:
        found_byte = codebook[real_target]
        known_flag += found_byte
        log.info(f"Flag: {known_flag.decode("latin-1")}")
    else:
        log.error("Not found.")


Sends padding+known_flag+guess_byte for every printable ASCII letter and builds a codebook with the ciphertext and the letter. Then sends padding for the padding+flag mode, sees if the value matches with anything inside our codebook and appends to known_flag, and repeats. After a while of doing these I noticed that I could go about it the other way, by getting the padding+flag and iterating for every ASCII letter until we get a hit, when I changed the code to try it out it went from 7 seconds to 4 seconds to get the flag.

23) DHKE

The challenge program will have us carry out a DHKE (Diffie-Hellman Key Exchange). For this, the program will give us the values
p, g, A, and ask us the value of B. 'a' is the secret value of the other party, and 'b' is our secret value, these are never exchanged.
Since A is the product of pow(g, a, p) we will come up with a B of our own, which will be pow(g, b, p), b being our arbitrary value, and send it to the program. This time, it will ask us for 's'. The other party would have done s = (B ^ a) mod p, and in our case we will do s = (A ^ b) mod p, which will have equivalent values. We can get s by doing pow(A, b, p), send the value to the program and get our flag.
